# SHANLE LAB 店铺设计接续说明

更新：2026-11-19。用途：供 ChatGPT Web「👀shanlelab」与本地工作接续。此文为本次核对快照；后续具体项目以共享工作区对应清单和用户最新明确指示为准。不是生产批准书。

## 工作方式与设计方法

- 用户优先看图：“我不看字，我看图，你用图说话”。交付先给实际图或明确图片链接，再给简短解释；只给合集入口不够。
- 必须实际打开用户提供的链接、附件、原稿和实拍；打不开或只读部分要说清楚。定位文件、提取文字、实际看过图片是不同状态，不能互相冒充。
- “主角系列带动整体展位”：选有辨识度的代表产品/系列，将其真实图形、颜色、纹样与文化语言延伸到背景、桌面、招牌和物料；其他系列保留个性，以共同主题和品牌框架统一。平面主角必须有相应实物陈列重心，避免背景讲一套、货架讲另一套。
- 原始产品图、包装轮廓、用户指定面稿、CAD和PDF原图优先；不得默默重画、拉伸、替换。AI场景只证明视觉设想，不证明轮廓、尺度、挂位、材料、承重、可制造或安装验收。
- 以真实场地、现有道具、能携带与安装的结构为依据。选款展示、POP在包/箱/耳机/帽子等处的应用、体验、取货与补货一起安排；正面展示位、不同SKU与库存量分别核算。
- 尺寸须写单位与依据，标出实测、用户指定、图面标注和暂拟值；人与商品比例、最高排取货、柜门/通道净空需核对。互动3D是几何筛查，不能代替实人试取和制造确认。
- 各场地与项目独立。不得把niko、SPACE、NOWRE、MLBB、凡几的尺寸、库存、方案编号和否决状态相互移植。
- 严格区分：已生成、候选、用户选定、已发送、对方打开、批准、生产/安装验收。版本号更高不代表被选定。否决图退出当前推荐，历史仍可追溯；已取消范围不能因找到旧文件而恢复。
- 保持一个当前完整入口；旧版用Git历史/明确历史区保存。完成新成果或方案选择/取消后，默认同步已收录共享工作区；仅本地/暂不发布的要求优先。只提交本任务内容，保护其他对话的修改。
- 不公开完整聊天、成本/结算价、活动答案、协议原件或凭据。
